## Three rules

**One home per fact, named before the code is written.** `build-plan.md` §4 assigns every
kind of statement a document, and two of its tasks are doc changes that land in the same PR
as the code.

**Provenance.** A claim earns a place in a live document only on a passing test, a
re-runnable probe, or a code location read directly.

**A measurement carries its configuration** — soil layer count, driver, tolerances, lifetime,
trait set. A conclusion inherits its probe's degeneracies.
