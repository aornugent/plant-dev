`advance_recorded(rec)` steps a System through a recorded run's steps and hands each stage evaluation the recorded row as `const`, so the System reads every value the recorded run solved for.

A System that takes some of the row's values and solves the others itself has nowhere to put what it solves. plant's invader is one: it reads the resident stand's light environment from the row and must solve its own leaf. Today it can only read the resident's leaf values, so the invader's fitness is computed at the resident's leaf, and a reverse sweep of the invasion reads the resident's values too.
