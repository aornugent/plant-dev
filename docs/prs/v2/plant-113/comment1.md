coordinate, at `ode_tol` 1e-3.

## Terms

- **the pool's own rate** λ = (charge + drain) / storage_max, the rate at
  which TF24's storage pool relaxes toward its equilibrium. charge and
  drain are the two non-negative flows #609 split net production into.
- **relaxation offset** `storage_relaxation_offset`, o: time added to the
  pool's own relaxation time 1/λ, so the pool relaxes at λ/(1 + λo).
- **stage below empty**: a Cash-Karp stage state with negative storage.
  The base threw on one (`TF24 storage is negative`); this branch
  evaluates it.

## Control flow

What happens to a stage that lands below empty, and to a step that ends
there:

```
  odelia step (Cash-Karp, six stages)
    └─ Patch::compute_rates → TF24_Strategy::compute_rates
         storage < 0 at a stage
           base:   util::stop_domain("TF24 storage is negative ...")
           branch: rates finite; at r < 0 the pool's rate is
                   (charge - (charge + drain) r) / (1 + λo) > 0
    │
    ├─ adaptive resident step
    │    base:   the throw rejects the attempt; retry smaller
    │    branch: the error estimate rejects an inaccurate attempt;
    │            Patch::ode_state_valid() (non_negative_states(): storage)
    │            rejects an end below empty; retry smaller
    │
    ├─ fixed-size step (advance_fixed)
    │    either refusal subdivides the interval
    │
    └─ invasion: the resident's recorded steps, one row each
         a refusal cannot shrink a recorded step, so the invasion stops
         base:   at the stage throw, on every invader tried
         branch: only at a refused end, which the offset makes rare
```
